# FIVEOUT

FIVEOUT is a possession-by-possession basketball simulator. Build an eight-player rotation from current or all-time players, tune the tactics, watch the game unfold on a 2D court, or challenge a friend in classic and alternating draft formats.

## Local development

1. Copy the required Supabase and data-service variables into `.env.local`.
2. Install dependencies with `npm install`.
3. Start the app with `npm run dev`.
4. Open `http://localhost:3000`.

The original QNBA project remains separate. This repository is the standalone FIVEOUT product.
